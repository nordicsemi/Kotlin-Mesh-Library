# Module core

Provides the core functionality in a Bluetooth Mesh Network.

The module contains the mesh network database (`MeshNetwork`) and its serialization, the mesh
network layers, and the supported foundation, generic, sensor and health messages.

# Package no.nordicsemi.kotlin.mesh.core

Entry point of the library, including the `MeshNetworkManager`.

# Package no.nordicsemi.kotlin.mesh.core.exception

Exceptions thrown by the mesh core.

# Package no.nordicsemi.kotlin.mesh.core.layers

The Bluetooth Mesh stack layers: network, lower transport, upper transport and access.

# Package no.nordicsemi.kotlin.mesh.core.messages

Mesh messages and their base types.

# Package no.nordicsemi.kotlin.mesh.core.model

The Bluetooth Mesh network database: nodes, elements, models, keys, groups, scenes, provisioners.

# Package no.nordicsemi.kotlin.mesh.core.model.serialization

Serialization of the mesh network to and from the Mesh Configuration Database JSON format.

# Package no.nordicsemi.kotlin.mesh.core.oob

Out-of-band types used during provisioning.

# Package no.nordicsemi.kotlin.mesh.core.util

Utilities used by the mesh core.
