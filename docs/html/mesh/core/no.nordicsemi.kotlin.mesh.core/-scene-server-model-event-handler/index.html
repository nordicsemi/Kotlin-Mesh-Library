SceneServerModelEventHandler

abstract class SceneServerModelEventHandler : ModelEventHandler

This event handler should be used when defining Scene Server model. In addition to handling messages, the Scene Server delegate should also clear the current whenever StoredWithSceneModelEventHandler.store and StoredWithSceneModelEventHandler.recall are called.

Whenever the state changes due toa ny other reason than receiving a Scene Recall message, the delegate should call StoredWithSceneModelEventHandler.networkDidExitStoredWithSceneState to clear the current scene.
