DeviceProperty

enum DeviceProperty : Enum<DeviceProperty>

Device Properties specified in Mesh Device Properties.

Each property has a corresponding DevicePropertyCharacteristic.

Not all properties have their corresponding characteristics implemented in this library. For those valueLength is null and DevicePropertyCharacteristic.Other is returned when the value is read.
