FirmwareDistributionStatus

class FirmwareDistributionStatus : ApplicationResponse, FirmwareDistributionStatusMessage

The Firmware Distribution Status message is an unacknowledged message sent by a Firmware Distribution Server to report th status of a firmware image distribution

A Firmware Distribution Status message is sent as a response to any of FirmwareDistributionGet, FirmwareDistributionStart, FirmwareDistributionSuspend, FirmwareDistributionCancel, FirmwareDistributionApply messages.
